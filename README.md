# Scientific Research

Nine entry workflows for OpenDiscovery: literature review, research lookup, citations, source verification, manuscript writing, peer review, brainstorming, hypotheses and experimental design.

Install from Discover → Science → Scientific Research. Research workflows use the tools and database skills available in your instance. External services require their own connections. No provider account is included.

## Supporting resources

References, templates and scripts ship with their skills. Optional numerical analysis scripts require the Python packages listed in their instructions; set up a project environment explicitly before running them. Manuscript PDF compilation requires a configured TeX runtime. These dependencies are not installed automatically. Do not claim a calculation or compilation succeeded unless its output was produced and checked.

Use the package update action to obtain new versions. Disabling or removing this package withdraws its skills without deleting project outputs.
