# Life Sciences Databases

A complete package of 44 scientific database skills for OpenDiscovery. Query public life-science resources across genetics, proteins, chemistry, pathways, clinical evidence and omics.

Install from Discover → Science → Life Sciences Databases. Review the declared skills, then approve their activation. The package does not start background MCP servers.

## Requirements

Python 3.10 or newer on the OpenDiscovery Engine host. Pinned pure-Python HTTP dependencies are included in the package; no pip installation is needed for the shared REST helpers. Credentials and access restrictions vary by database; follow the selected skill's instructions. Run scripts from their skill directory or use their absolute installed paths. The package includes shared scripts and references; keep its directory structure intact.

## Updates

Use the package update action in OpenDiscovery. Disable or remove the package to withdraw its skills; saved research files remain in your project.
